# 🎮 PlayZone — Browser Gaming Portal

A modern, responsive, and neon-themed browser gaming portal built with **React**, **Vite**, and **Vanilla CSS**. PlayZone features playable HTML5 canvas games, real-time search & filters, game details with fullscreen play mode, and modern UI/UX design.

![PlayZone Banner](https://images.unsplash.com/photo-1550745165-9bc0b252726f?auto=format&fit=crop&w=1200&q=80)

---

## 🚀 Features

- **🎮 6 Playable Canvas & Logic Games:**
  - 🐍 **Neon Snake**: Cyberpunk themed snake with fruit spawning, combo trails, and dynamic speed.
  - 🚀 **Space Defender**: Classic top-down space shooter with waves of invaders, shooting lasers, and boss enemies.
  - 🧱 **Retro Brick Breaker**: Arcade brick buster with power-ups and paddle controls.
  - 🔢 **2048 Neon**: Smooth numeric tile merging puzzle.
  - 🧠 **Memory Matrix**: Pattern memory and card flipping brain game.
  - ⚡ **Speed Math**: Fast-paced reflex mental arithmetic challenge with streak multipliers.

- **🎨 Modern Cyberpunk / Dark UI:**
  - Dark navy/charcoal glassmorphism backdrop with neon blue & purple glow accents.
  - Smooth micro-animations, category badges, and star ratings.
  - Responsive design adapting seamlessly to mobile, tablet, and desktop screens.

- **🔍 Search & Filtering:**
  - Instant live game search with tag filtering (Action, Arcade, Puzzle).
  - Sort by popularity, rating, or release date.

- **📱 Fullscreen & Accessible:**
  - Dedicated individual game pages with fullscreen toggle.
  - Accessible keyboard navigation and ARIA landmarks.
  - Educational disclaimers, About, Contact, Privacy, and Terms of Service pages.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite
- **Routing:** React Router v7 (`react-router-dom`)
- **Styling:** Pure Vanilla CSS (CSS Variables, Flexbox, CSS Grid)
- **Game Engines:** Pure HTML5 Canvas & JavaScript Engines (No external heavy game frameworks required)

## 📦 Getting Started

### 1. Clone the repository:
```bash
git clone https://github.com/Sayma2025/playzone.git
cd playzone
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Run the development server:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production:
```bash
npm run build
```
